Gossil

Gossil aims to keep agent work, issues and file history together alongside Git. Fossil is a version-control system. This build exposes a Rust library for its delta bytes, artifact parsing and local storage. The gossil command creates, applies and checks deltas between files without a version-control checkout. It also initializes an empty repository through vcs init, without creating a checkout. The source vcs open command registers or reopens one empty-root checkout and publishes its lookup locator without selecting files.

Start with a file round trip, browse the CLI reference, or use the Rust API reference. Use working with repositories to plan agent files alongside Git. It explains checkouts, stored history and the intended private and shared workflows.

For an already installed development preview, try the disposable file-history walkthrough. The preview is unmerged.

Read compare Gossil with Git for the planned coordination of file history, exact issue state and versioned links to code. The examples show library calls for deltas, compressed bytes, hashes and token escaping.

Gest is a task and artifact tracker. The converters in the module table use its task, project and author record model.
