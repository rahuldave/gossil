Manage agent-generated artifacts and task backlogs alongside your project

https://gest.aaronmallen.dev

Gest provides a lightweight, file-based system for organizing the artifacts, specs, ADRs, and task backlogs that AI coding agents produce. Instead of letting generated context scatter across chat logs and throwaway files, gest stores it in a structured, version-controlled directory right inside your repo — so every decision, plan, and backlog item travels with the code it describes. It includes a local web dashboard for browsing and managing your project's knowledge base, and a CLI that integrates naturally into agent-driven workflows.
