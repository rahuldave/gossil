pub fn entry() -> std::process::ExitCode

Print the adapter error once, with the native newline and exit status.

Panics

Panics if writing an error diagnostic to standard error fails.

Parameter Type Description
returns std::process::ExitCode The success exit code after initialization, native checkout open or a completed diagnostic, or the failure exit code after printing its error to standard error. The first argument v is accepted as an alias for vcs.
