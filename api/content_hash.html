fn sha1

source

pub fn sha1(input: &[u8]) -> [u8; 20]

Hash bytes with Fossil’s collision-detecting SHA-1 safe-hash mode.

On an attack collision, return the mitigated digest. Like Fossil’s sha1sum_blob, this byte helper ignores the separate collision indication.

Examples

assert_eq!(gossil::content_hash::sha1(b"abc").len(), 20);
Parameter Type Description
input &[u8] Complete byte content.
returns [u8; 20] The twenty binary digest bytes.

fn sha3

source

pub fn sha3(input: &[u8], bits: u16) -> Option<Vec<u8>>

Hash bytes with Fossil’s SHA3 padding and width-dependent capacity.

This small sponge adapter ports SHA3Init, SHA3Update and SHA3Final; the maintained keccak crate supplies the complete permutation. It does not truncate a standard-width digest to produce a nonstandard width.

Examples

assert_eq!(gossil::content_hash::sha3(b"abc", 160).unwrap().len(), 20);
Parameter Type Description
input &[u8] Complete byte content.
bits u16 A multiple of 32 from 128 through 512.
returns Option<Vec<u8>> Binary digest bytes, or None for an unsupported width.
