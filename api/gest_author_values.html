gest_author_values

Convert complete admitted canonical author fields into owned values. Validate complete canonical author values in memory. Native actors and local principals stay separate.

Supply all six fields explicitly. Conversion generates no identity or time and performs no storage.

Recommendations

Validate complete author inputs before native integration. Keep names and nullable email exact.

struct AuthorValueInputs

source

pub struct AuthorValueInputs

Supply complete author fields, with SQL-null email represented as JSON null.

Field Type Description
gest_id Value Supply the full inherited author identity.
author_type Value Supply human or agent under the inherited case-insensitive grammar.
name Value Preserve the exact unrestricted display name.
email Value Supply explicit null or an exact unrestricted email string.
created_at Value Supply the explicit creation instant.
updated_at Value Supply the explicit last-modified instant.

Implements Clone, Debug, PartialEq.

fn author_from_values

source

pub fn author_from_values(fields: AuthorValueInputs) -> Result<AuthorValues, AuthorValueError>

Validate all six fields, preserving empty strings and nullable email distinctly.

Errors

Reject wrong types, identifiers other than 32 lowercase letters from k through z, author types other than case-insensitive human or agent, and invalid RFC3339 timestamps. Also reject normalized UTC output that cannot be parsed again as RFC3339. Names and string emails are unrestricted. Null email differs from an empty string.

Examples

use gossil::gest_author_values::{AuthorValueInputs, author_from_values, author_to_values};
use serde_json::json;
let author = author_from_values(AuthorValueInputs {
    gest_id: json!("kkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkk"),
    author_type: json!("AGENT"),
    name: json!(" Alice "),
    email: json!(null),
    created_at: json!("2026-11-19T01:02:03.000000001+02:00"),
    updated_at: json!("2020-01-01T00:00:00Z"),
}).unwrap();
let values = author_to_values(&author);
assert_eq!(values.author_type, json!("agent"));
assert_eq!(values.email, json!(null));
assert_eq!(author_from_values(values).unwrap(), author);
Parameter Type Description
fields AuthorValueInputs Supply complete canonical author fields after admission checks.
returns Result<AuthorValues, AuthorValueError> Return validated owned fields with canonical UTC instants and no timestamp ordering rule.

pub fn author_to_values(record: &AuthorValues) -> AuthorValueInputs

Return the six canonical fields with exact strings and canonical UTC timestamps.

Parameter Type Description

returns AuthorValueInputs Return independent owned values that preserve null email separately from a present empty string. See author_from_values for a complete round-trip example.
