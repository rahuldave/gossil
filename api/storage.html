storage

Own local database connections and exclusive write boundaries. Sole-connection local storage. File opens verify WAL, foreign keys, FULL and 5000 ms. Unexpected owner destruction poisons the store and closes its connection. Local SQL blocks its current poll; cancellation after COMMIT cannot undo it.

The core-only native provider has a reviewed date backport. Its source identity is recorded in evidence/libsql-provider/provenance.json. Native repository creation and admission parse the empty root on this same connection. General artifact crosslinks, runtime clocks and broader date compatibility remain unqualified. Catalog6 supports native initialization, one registration and exact private recorded history; bound catalog1 retains private writes. A marker of an older Gossil catalog (2, 4 or 5) is refused before any effect, without migration.

Recommendations

Use one owner for a complete mutation and explicitly commit or roll back. Use LocalOwnerRepository for admitted native content and explicit finite limits.

LocalOwnerRepository::recorded_timeline_page

source

pub async fn recorded_timeline_page(
    &mut self,
    checkout: &str,
    offset: usize,
    limit: usize,
    limits: AdmissionLimits,
) -> Result<Vec<RecordedCheckin>, StorageError>

Read one page of the native ancestry of an explicitly selected checkout.

The ancestry starts with the current private check-in, follows its first parents, and ends with the immutable shared empty root. Before the first private recording, that root is the only entry. The page skips the first offset entries and then holds at most limit entries, or every remaining entry when limit is 0, as the --offset and --limit options of fossil timeline do.

One transaction runs the checks of each command, then walks the manifests from the current check-in to the end of the page, and reads the event row of each entry of the page. Each manifest has the ceilings of one artifact, and each row the ceilings of one row. The read has no ceiling on the whole chain, so its cost follows offset and limit, not the length of the history.

The read refuses an event whose user or comment is not the U or C card of its manifest. When the walk reaches the shared root, it also refuses a chain whose length is not the generation of the checkout. It reads no file content, makes no durable mutation and publishes no locator. Pending paths and working files do not change the result.

Errors

Refuses missing/foreign checkout, changed authority, unsupported or corrupt state, invalid limits, an artifact or row over its ceiling, allocation/provider and checked cleanup errors. Existing operation causes and separate cleanup failures are preserved.

Examples
async fn newest(owner: &mut gossil::storage::LocalOwnerRepository, limits: gossil::storage::AdmissionLimits) {
    let rows = owner.recorded_timeline_page("work", 0, 20, limits).await.unwrap();
    assert!(rows.len() <= 20);
}
Parameter Type Description
checkout &str Existing nonempty NUL-free registration ID, at most 1024 bytes and parser input bytes.
offset usize The count of newest entries to skip.
limit usize The most entries to return, or 0 for every remaining entry.
limits AdmissionLimits The ceilings of one artifact and one row. The total content ceilings are not used.
returns Result<Vec<RecordedCheckin>, StorageError> The entries of the page, newest first, only after checked transaction completion. The page is empty only when offset passes the shared root.

LocalOwnerRepository::create_private_issue

source

pub async fn create_private_issue(
    &mut self,
    request: PrivateIssueRequest<'_>,
    limits: IssueLimits,
) -> Result<IssueTicket, StorageError>

Store one private task or project creation artifact in one transaction.

The call runs the checks of each command. It parses the artifact and checks that it is one canonical creation. It checks that no row holds its ticket ID, tag, artifact or Gest ID, and that the project of a task exists and is not archived. It then writes the native rows of a private Fossil ticket and one typed row, runs the checks of each command again, and commits. Each check uses an index, so the cost of the call does not grow with the repository.

Errors

Refuses a shared scope, the refusals of the checks of each command and an artifact that is not one canonical creation. Also refuses a [ in a J value, a ticket ID, tag, artifact or Gest ID that a row already holds, a task whose project is missing or archived, exhausted ceilings and SQL failures. The refusal writes nothing.

Examples
use gossil::storage::{IssueLimits, IssueTicket, LocalOwnerRepository, PathScope,
    PrivateIssueRequest, StorageError};
async fn store(owner: &mut LocalOwnerRepository, artifact: &[u8], limits: IssueLimits)
    -> Result<IssueTicket, StorageError> {
    owner.create_private_issue(PrivateIssueRequest { artifact, scope: PathScope::Private },
        limits).await
}
Parameter Type Description
request PrivateIssueRequest<'_> The creation artifact and the requested scope.
limits IssueLimits Finite content, parser and SQL ceilings for the whole call.
returns Result<IssueTicket, StorageError> The stored ticket ID, native name and record.

pub async fn verify_issue(
    &mut self,
    id: &str,
    limits: AdmissionLimits,

Prove one task or project from its own rows.

The ticket whose gest_id names the ID must be the only one. The proof then replays its one artifact and compares its event, tagxref, ticket, ticketchng and combined typed rows with that replay. It refuses a row of the unsent, unclustered, leaf, phantom, orphan, backlink, attachment, mlink or plink table that names the artifact or the ticket.
