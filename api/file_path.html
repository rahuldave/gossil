file_path

Simplify filename bytes by the bounded lexical rules of Fossil. Simplify filename bytes in a bounded port of the lexical rules of Fossil src/file.c.

The original code is copyright 2006 D. Richard Hipp, under the 2-Clause BSD license. The license text is in tests/fixtures/file-path/COPYRIGHT-BSD2.txt.

The module ports the Unix branch and the Windows/Cygwin branch of file_simplify_name and backup_dir from Fossil check-in 7e8ecf0ce4. It does not read the filesystem, resolve symlinks, authorize paths or make names absolute. The tests of the source branches do not show that the code runs correctly on a native Windows or Cygwin host. No test has run on such a host. The input is a complete byte name with no NUL, and an empty input stays empty.

Recommendations

Set explicit limits for the application, and treat the result as lexical bytes. Next, apply the filesystem and containment policy of the caller in a separate step.

enum PathError

pub enum PathError

PathError reports a rejected input, an exceeded bound or a failed allocation.

Variant Description
InputLimit The input exceeds the bound of the caller or the largest buffer that memory can address.
OutputLimit The simplified output exceeds the bound of the caller.
EmbeddedNul The input contains a NUL, which has no accepted meaning in a filename.
TerminalCancellation The native simplification would write its terminator before the start of the buffer.
Allocation(TryReserveError) The reservation of the buffer failed before the input was copied.

Implements Debug, Display, Error.

fn simplify_name

source

pub fn simplify_name(
    input: &[u8],
    keep_trailing_slash: bool,
    limits: Limits,
) -> Result<Vec<u8>, PathError>

Simplify a filename with no NUL by the Unix lexical rules of Fossil.

Duplicate separators collapse to one, but an initial double slash stays. The function removes a leading ./, each internal /./ and each /component/.. that can cancel. Unresolved .. components stay, even above an absolute root. As in native Fossil, a nonempty name whose simplified bytes are empty becomes /.

A relative name that cancels past its start, such as a/.., is a relative terminal cancellation. It leaves native C with a negative cursor and a terminator outside the buffer, and this function rejects it.

The input buffer holds at most max_input_bytes plus one sentinel byte. The output bound applies to the actual length of the simplified name.

Errors

Returns PathError for an exceeded bound, a NUL, a failed allocation or a relative terminal cancellation.

Examples

use gossil::file_path::{Limits, simplify_name};
let bounds = Limits { max_input_bytes: 128, max_output_bytes: 128 };
assert_eq!(simplify_name(b"a/b/../c/", false, bounds).unwrap(), b"a/c");
Parameter Type Description
input &[u8] The complete filename bytes, with no embedded NUL.
keep_trailing_slash bool Keep a trailing separator where the native rules keep it.
limits Limits The bounds of the caller on the input bytes and the output bytes.
returns Result<Vec<u8>, PathError> The owned simplified bytes, without a terminating NUL.

fn simplify_name_for_source

source

pub fn simplify_name_for_source(
    input: &[u8],
    keep_trailing_slash: bool,
    limits: Limits,
    platform: SourcePlatform,
) -> Result<SimplifiedName, PathError>

Simplify a filename by the branch of the Fossil source that the caller selects.

The Windows/Cygwin branch converts every backslash to a slash. Then it removes //?/ and compares the next three bytes with UNC, by the ASCII case map of SQLite. The function does not check drives, the names after the UNC prefix or whether a name is valid. For the input //?/, native C copies the terminator of the input to byte zero but reports a length of one. So the result keeps that NUL in its reported span, and its visible C string is empty.

The input buffer holds at most the length of the input plus one sentinel byte. The output bound counts the reported span, with any NUL inside that span. After the loops compact the name, the native lookahead can still read the original bytes at the end of the buffer. A relative terminal cancellation returns the same error as simplify_name.

Errors

Returns PathError for an exceeded bound, a NUL, a failed allocation or a relative terminal cancellation.

Examples

use gossil::file_path::{Limits, SourcePlatform, simplify_name_for_source};
let bounds = Limits { max_input_bytes: 128, max_output_bytes: 128 };
let windows = SourcePlatform::WindowsCygwin;
let unc = simplify_name_for_source(b"\\\\?\\UNC\\a\\b", false, bounds, windows).unwrap();
assert_eq!(unc.visible_bytes(), b"//a/b");
let prefix = simplify_name_for_source(b"//?/", false, bounds, windows).unwrap();
assert_eq!(prefix.reported_span(), b"\0");
assert!(prefix.visible_bytes().is_empty());
Parameter Type Description
input &[u8] The complete filename bytes, with no NUL.
keep_trailing_slash bool The native option to keep a trailing slash.
limits Limits The bounds on the input and on the reported output span.
platform SourcePlatform The source branch to apply, whatever the host.
returns Result<SimplifiedName, PathError> The bytes that the native code reports, with a separate accessor for the visible C string.
