artifact

Parse structural artifacts with explicit resource limits. Parse bounded structural artifacts with an explicit date provider.

This module ports Fossil manifest.c (Copyright 2007 D. Richard Hipp, Simplified BSD).

struct ParseLimits

source

pub struct ParseLimits

Set the caller’s resource policy with no universal default.

Field Type Description
input_bytes usize Maximum complete input size.
cards usize Maximum number of structural cards.
owned_bytes usize Maximum logical owned-byte charges, including retained input and encoded tokens.
entries usize Maximum total list entries across all cards.

Implements Debug, Clone, Copy.

struct ParseUsage

source

pub struct ParseUsage

Report the exact resource charges of one successful parse.

These counters use the same accounting as ParseLimits, including conservative encoded token charges rather than decoded lengths. Subtract them from an operation’s remaining limits before parsing another artifact. The counters report logical charges against ParseLimits, not every physical Rust allocator byte.

Field Type Description
input_bytes usize Complete raw input size, including any recognized signature envelope.
cards usize Nonzero structural card markers consumed, including Z but excluding a zero sentinel.
owned_bytes usize Total charged owned bytes, including copies, token charges and list entry sizes.
entries usize Total charged list insertions.

Implements Debug, Clone, Copy, PartialEq, Eq.

pub enum ArtifactError

Distinguish syntax, checksum, resource and provider failures.

Variant Description
Syntax { offset: usize, line: usize, message: &'static str } Malformed structural input, with byte cursor and card number.

fn parse_artifact

source

pub async fn parse_artifact(
    input: &[u8],
    limits: ParseLimits,
    dates: &impl DateProvider,
) -> Result<ParsedArtifact, ArtifactError>

Parse all eight structural artifact types with rid=0 semantics.

This validates grammar and exact MD5, not signatures, repository closure or R contents. Date conversion must use the caller’s selected SQLite/libSQL engine.

Examples

use gossil::artifact::{
    ArtifactError, DateProvider, ParseLimits, ParsedArtifact, parse_artifact,
};

async fn parse_for_operation(
    bytes: &[u8],
    dates: &impl DateProvider,
) -> Result<ParsedArtifact, ArtifactError> {
    let limits = ParseLimits {
        input_bytes: 1_048_576,
        cards: 10_000,
        owned_bytes: 4_194_304,
        entries: 10_000,
    };
    parse_artifact(bytes, limits, dates).await
}

Errors

Returns syntax, checksum, resource-limit or provider failure separately.

Parameter Type Description
input &[u8] Immutable raw artifact bytes, with any supported signature envelope.
limits ParseLimits Explicit input, card, owned-byte and list-entry bounds.
dates &impl DateProvider Asynchronous provider, which may borrow an existing transaction.
returns Result<ParsedArtifact, ArtifactError> An owned result exposing read-only parsed fields and the exact original bytes. Use parse_artifact_with_usage when the caller also needs resource charges.

fn parse_artifact_with_usage

source

pub async fn parse_artifact_with_usage(
    input: &[u8],
    limits: ParseLimits,
    dates: &impl DateProvider,
) -> Result<(ParsedArtifact, ParseUsage), ArtifactError>

Parse an artifact and report its existing resource counters on success.

Uses the same grammar and allocation checks as parse_artifact. No usage is returned on failure; an aggregate caller must stop its operation on an error.

Examples

Parse a cluster, which has no date card, and debit a caller-owned budget.

use gossil::artifact::{
    ArtifactError, DateProvider, DateProviderError, ParseLimits, parse_artifact_with_usage,
};
struct NoDates;
impl DateProvider for NoDates {
    async fn julianday(&self, _: Option<&[u8]>) -> Result<Option<f64>, DateProviderError> {
        Ok(None)
    }
}
let mut input = b"M aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa\n".to_vec();
let checksum = gossil::artifact_checksum::md5(&input);
input.extend_from_slice(b"Z ");
for byte in checksum {
    input.extend_from_slice(format!("{byte:02x}").as_bytes());
}
input.push(b'\n');
let mut remaining = ParseLimits {
    input_bytes: 4096, cards: 100, owned_bytes: 8192, entries: 100,
};
let (_, usage) = parse_artifact_with_usage(&input, remaining, &NoDates).await?;
assert_eq!(usage.input_bytes, input.len());
assert_eq!(usage.cards, 2);
assert_eq!(usage.entries, 1);
remaining.input_bytes -= usage.input_bytes;
remaining.cards -= usage.cards;
remaining.owned_bytes -= usage.owned_bytes;
remaining.entries -= usage.entries;
assert_eq!(remaining.cards, 98);

The successful charges fit the supplied limits, so these subtractions cannot underflow. On an error, stop and discard the enclosing operation state.

Errors

Returns syntax, checksum, resource-limit or provider failure separately.

Parameter Type Description
input &[u8] Complete raw bytes, including any supported signature envelope.
limits ParseLimits Remaining input, card, owned-byte and entry bounds for the operation.
dates &impl DateProvider Selected date provider, possibly borrowing the caller’s transaction.
returns Result<(ParsedArtifact, ParseUsage), ArtifactError> The validated artifact and the exact logical charges against the supplied limits. These charges do not measure every physical Rust allocator byte.
