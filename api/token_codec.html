token_codec

Encode and decode Fossil token bytes. Encode and decode Fossil token bytes without text conversion.

enum TokenError

source

pub enum TokenError

A size boundary or allocation failure in a safe token operation.

Variant Description
Size The exact encoded length cannot fit Rust vector capacity.
Allocation(TryReserveError) The allocator could not reserve output storage.

Implements Debug, Display, Error.

fn fossilize

source

pub fn fossilize(input: &[u8]) -> Result<Vec<u8>, TokenError>

Encode every supplied byte, including embedded NUL.

Errors

Returns TokenError::Size on encoded-size overflow or lengths above isize::MAX, or TokenError::Allocation if reservation fails.

Examples

assert_eq!(gossil::token_codec::fossilize(b"a b\0").unwrap(), b"a\\sb\\0");
Parameter Type Description
input &[u8] Arbitrary bytes, without UTF-8 requirements.
returns Result<Vec<u8>, TokenError> Encoded bytes without a C terminator.

fn fossilize_c_string

source

pub fn fossilize_c_string(input: &[u8]) -> Result<Vec<u8>, TokenError>

Encode bytes preceding the first NUL, or the full slice when absent.

Errors

Returns TokenError::Size on encoded-size overflow or lengths above isize::MAX, or TokenError::Allocation if reservation fails.

Examples

assert_eq!(gossil::token_codec::fossilize_c_string(b"a\0b").unwrap(), b"a");
Parameter Type Description
input &[u8] Bounded C-string contents; a terminator is optional.
returns Result<Vec<u8>, TokenError> Encoded prefix without a C terminator.

fn defossilize

source

pub fn defossilize(input: &[u8]) -> Result<DecodedToken, TokenError>

Decode bytes before the first source NUL or the slice end. Preserve all emitted bytes, including bytes after a decoded NUL. Unknown escapes discard the slash; a terminal slash survives.

Errors

Returns TokenError::Allocation if reservation fails before output is emitted.

Examples

let decoded = gossil::token_codec::defossilize(b"a\\0b").unwrap();
assert_eq!(decoded.bytes, b"a\0b");
assert_eq!(decoded.c_string_len, 1);
Parameter Type Description
input &[u8] Arbitrary bounded token bytes; a terminator is optional.
returns Result<DecodedToken, TokenError> Complete emitted bytes and their C-string prefix length.
