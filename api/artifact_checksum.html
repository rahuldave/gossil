artifact_checksum

Compute legacy Fossil artifact checksums over bytes. Compute legacy MD5 checksums for Fossil artifact bytes, separate from content identity.

The artifact parser uses this byte primitive for Z-card validation. It parses no artifact and exposes no filesystem or CLI adapter. MD5 supplies legacy compatibility, not a security hash.

struct Md5Checksum

source

pub struct Md5Checksum(/* private field */);

Compute an artifact checksum incrementally with owned state and fixed memory use.

Each value owns its state. Finishing consumes it. Create a fresh value to begin another computation. No C string scanning or global reset is exposed.

Examples

use gossil::artifact_checksum::{md5, Md5Checksum};
let mut checksum = Md5Checksum::new();
checksum.update(b"a");
checksum.update(b"bc");
assert_eq!(checksum.finish(), md5(b"abc"));

Implements Default.

Md5Checksum::update

source

pub fn update(&mut self, bytes: &[u8])

Append all bytes, including zero and non-UTF-8 bytes.

Empty updates leave the computation unchanged. No input is retained.

Parameter Type Description
bytes &[u8] Bounded bytes to append in order.

Md5Checksum::finish

source

pub fn finish(self) -> [u8; 16]

Consume this computation and return sixteen binary digest bytes.

Parameter Type Description
returns [u8; 16] MD5 of all appended bytes in order, including the empty input.

fn md5

source

pub fn md5(bytes: &[u8]) -> [u8; 16]

Compute the legacy MD5 checksum of the complete bounded byte slice.

This checksum is separate from repository content identity policy.

Examples

assert_eq!(gossil::artifact_checksum::md5(b"abc"),
    [0x90, 0x01, 0x50, 0x98, 0x3c, 0xd2, 0x4f, 0xb0,
     0xd6, 0x96, 0x3f, 0x7d, 0x28, 0xe1, 0x7f, 0x72]);
Parameter Type Description
bytes &[u8] Complete content, with no text encoding or terminator rules.
returns [u8; 16] The sixteen binary digest bytes.
