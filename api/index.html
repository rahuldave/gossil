Reference

Supply inherited-test tools, bounded byte primitives, Fossil glob matching, lexical filename simplification, check-in graph paths, a read-only Git reader, local storage, decoded task values and the Gest domain model.
Name Summary
artifact Parse structural artifacts with explicit resource limits. Parse bounded structural artifacts with an explicit date provider.
artifact_checksum Compute legacy Fossil artifact checksums over bytes. Compute legacy MD5 checksums for Fossil artifact bytes, separate from content identity.
compression Pack and unpack Fossil blobs with bounded zlib operations. Pack and unpack Fossil’s four-byte big-endian capacity and zlib stream.
content_hash Compute Fossil byte digests independently of repository hash policy. Compute Fossil byte digests independently of repository hash policy.
delta Create and apply bounded Fossil deltas; application leaves checksum verification disabled.
diff Compute bounded line edit scripts ported from Fossil’s src/diff.c.
file_path Simplify filename bytes by the bounded lexical rules of Fossil. Simplify filename bytes in a bounded port of the lexical rules of Fossil src/file.c.
gest_artifact_values Convert complete admitted canonical artifact fields into owned values. Convert 8 explicit decoded artifact fields into owned validated records.
gest_author_values Convert complete admitted canonical author fields into owned values. Validate complete canonical author values in memory. Native actors and local principals stay separate.
gest_entity_tag_values Convert complete admitted canonical entity_tag join fields into owned values. Convert 4 explicit decoded entity_tag fields into owned validated records.
gest_iteration_task_values Convert complete admitted canonical iteration_task join fields into owned values. Convert 4 explicit decoded iteration_task fields into owned validated records.
gest_iteration_values Convert complete admitted canonical iteration fields into owned values. Convert 9 explicit decoded iteration fields into owned validated records.
gest_model Hold the Gest domain model and its primitive values, copied from the pinned Gest source. The Gest domain model, with one record type for each Gest entity and the primitive values that they use.
gest_note_values Convert complete admitted canonical note fields into owned values. Convert 7 explicit decoded note fields into owned validated records.
gest_project_values Convert complete admitted canonical project fields into owned values. Complete owned conversion of the 4 canonical project fields.
gest_relationship_values Convert complete admitted canonical relationship fields into owned values. Convert 8 explicit decoded relationship fields into owned validated records.
gest_tag_values Convert complete admitted canonical tag fields into owned values. Convert 4 explicit decoded tag fields into owned validated records.
gest_task_values Convert independently admitted Gest task fields into validated owned values. Convert complete, already decoded task fields without storage or raw JSON parsing.
gest_ticket Emit the bounded bytes of artifact and project creation tickets through the shared Gest ticket emitter. Emit bounded Fossil ticket creation bytes for Gest artifact and project records.
git_reader Read Git commits, refs and settings beside Git, read-only, through pinned gix crates. Read Git commits, refs and repository settings beside Git, and never write to Git.
glob Bounded Fossil glob parsing, matching and SQL expression construction. Bounded source port of Fossil src/glob.c, copyright 2011 D. Richard Hipp. Original code is under the 2-Clause BSD license; see evidence/glob/fossil-license.txt. Matching calls the same libSQL SQLite engine as the storage boundary. Byte and pattern-count limits do not bound matching CPU time or stack use.
gossil Supply inherited-test tools, bounded byte primitives, Fossil glob matching, lexical filename simplification, check-in graph paths, a read-only Git reader, local storage, decoded task values and the Gest domain model.
history Find shortest paths and common ancestors in an explicit check-in graph, as Fossil does. Port the check-in graph searches of Fossil src/path.c and src/pqueue.c, with finite bounds.
native_date Represent validated native dates as integer nanoseconds. Represent Fossil artifact creation dates as Gregorian UTC integer nanoseconds.
product Shared implementation for both product executable names. Route native initialization, checkout open, information, tracking, recording, timeline, delta and glob diagnostics, and the recognised commands of the issue group.
storage Own local database connections and exclusive write boundaries. Sole-connection local storage. File opens verify WAL, foreign keys, FULL and 5000 ms. Unexpected owner destruction poisons the store and closes its connection. Local SQL blocks its current poll; cancellation after COMMIT cannot undo it.
task_ticket Emit bounded task creation ticket bytes. Emit bounded Fossil task ticket bytes for task creation.
token_codec Encode and decode Fossil token bytes. Encode and decode Fossil token bytes without text conversion.
