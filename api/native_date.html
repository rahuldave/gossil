native_date

Represent validated native dates as integer nanoseconds. Represent Fossil artifact creation dates as Gregorian UTC integer nanoseconds.

Here, native dates are the creation dates in Fossil artifact D cards. The supported range is years 0001 through 9999. This date domain is separate from Gest business timestamp parsing in crate::gest_task_values. Display always uses nine fractional digits without a UTC suffix.

NativeDate::parse

source

pub fn parse(input: &[u8]) -> Result<Self, DateError>

Parse exactly YYYY-MM-DDTHH:MM:SS[.fraction][Z], rejecting other spellings. A missing suffix means UTC. A present fraction has one through nine digits.

Examples
use gossil::native_date::NativeDate;
let date = NativeDate::parse(b"1969-12-31T23:59:59.999999999Z")?;
assert_eq!(date.epoch_nanos(), -1);
assert_eq!(date.to_string(), "1969-12-31T23:59:59.999999999");
Errors

Rejects invalid grammar or calendars, year zero, offsets, leap seconds and fractions over nine digits.

Parameter Type Description
input &[u8] ASCII native UTC date bytes.
returns Result<Self, DateError> The validated instant.
