glob

Bounded Fossil glob parsing, matching and SQL expression construction. Bounded source port of Fossil src/glob.c, copyright 2011 D. Richard Hipp. Original code is under the 2-Clause BSD license; see evidence/glob/fossil-license.txt. Matching calls the same libSQL SQLite engine as the storage boundary. Byte and pattern-count limits do not bound matching CPU time or stack use.

Lists use comma and ASCII-whitespace delimiters. A leading single or double quote retains delimiters until the same closing quote; an unmatched quote consumes the remaining prefix. There is no quote escape syntax. Every input ends at its first NUL. Matching returns the first one-based index, or zero.

glob_expr retains a distinct extra byte advance after a closing quote. Its value argument is trusted SQL. Bind untrusted candidate values separately. These functions perform no traversal, settings lookup or tracking mutation.

Recommendations

Use glob_create for repeated matching and glob_multi_match for one scan. Next, set explicit byte/count budgets and bind candidate values separately when executing SQL from glob_expr.

struct Limits

source

pub struct Limits

Supply finite byte/count budgets; input byte lengths stop before the first NUL. Prefix detection itself scans the original slice until NUL or its end. These budgets do not impose a separate CPU-time or stack limit.

Field Type Description
list_bytes usize Maximum pattern-list bytes.
candidate_bytes usize Maximum candidate bytes.
patterns usize Maximum number of parsed patterns.
expression_bytes usize Maximum SQL expression bytes, including the caller’s value expression.

Implements Clone, Copy, Debug.

Glob::glob_match

source

pub fn glob_match(&self, candidate: &[u8]) -> Result<usize, GlobError>

Return the first matching one-based pattern index, or zero.

The candidate ends at its first NUL. Matching uses the selected SQLite engine; byte budgets do not bound engine CPU time or stack use.

Examples
use gossil::glob::{glob_create, Limits};
let limits = Limits { list_bytes: 64, candidate_bytes: 64,
                      patterns: 8, expression_bytes: 256 };
let glob = glob_create(Some(b"a*,*.rs"), limits)?;
assert_eq!(glob.glob_match(b"abc.rs")?, 1);
assert_eq!(glob.glob_match(b"lib.rs")?, 2);
assert_eq!(glob.glob_match(b"notes.md")?, 0);
Errors

Returns GlobError::Limit when candidate bytes exceed the retained budget, GlobError::Overflow for terminator capacity arithmetic, or GlobError::Allocation when copying the candidate fails.

Parameter Type Description
candidate &[u8] Candidate bytes, ending at the first NUL.
returns Result<usize, GlobError> The first matching one-based pattern index, or zero when no pattern matches.

fn glob_create

source

pub fn glob_create(list: Option<&[u8]>, limits: Limits) -> Result<Glob, GlobError>

Parse a reusable Fossil pattern list; absent or delimiter-only lists match nothing.

Only an initial quote opens a quoted term. Commas and ASCII whitespace delimit unquoted terms, unmatched quotes consume the remainder, and empty quoted terms remain patterns. The list ends at its first NUL; no escape syntax is applied.

Examples

use gossil::glob::{glob_create, Limits};
let limits = Limits { list_bytes: 64, candidate_bytes: 64,
                      patterns: 8, expression_bytes: 256 };
let glob = glob_create(Some(b"*.rs,src/*"), limits)?;
assert_eq!(glob.glob_match(b"src/lib.rs")?, 1);
assert_eq!(glob.patterns().len(), 2);

Errors

Returns GlobError::Limit when list bytes or pattern count exceed their budgets, GlobError::Overflow for capacity arithmetic, or GlobError::Allocation when reservation fails.

Parameter Type Description
list Option<&[u8]> Optional pattern list; None has the same meaning as an empty list.
limits Limits Finite input, pattern and output budgets.
returns Result<Glob, GlobError> Owned parsed patterns and the retained candidate budget.

fn glob_multi_match

source

pub fn glob_multi_match(
    list: Option<&[u8]>,
    candidate: &[u8],
    limits: Limits,
) -> Result<usize, GlobError>

Match a Fossil list once and return the first one-based match index, or zero. A matching term returns immediately, without checking later terms against the pattern-count limit. Terms below 100 bytes use a temporary stack buffer; longer terms use a fallible allocation. Neither choice bounds engine recursion.

Errors

Returns GlobError::Limit when list bytes, candidate bytes or an inspected pattern count exceed their budgets, GlobError::Overflow for terminator capacity arithmetic, or GlobError::Allocation when reservation fails.

Examples

use gossil::glob::{glob_multi_match, Limits};
let limits = Limits { list_bytes: 64, candidate_bytes: 64,
                      patterns: 1, expression_bytes: 256 };
// Early success does not inspect the second term against the count budget.
assert_eq!(glob_multi_match(Some(b"a*,b*"), b"abc", limits)?, 1);
assert!(glob_multi_match(Some(b"a*,b*"), b"zzz", limits).is_err());
Parameter Type Description
list Option<&[u8]> Optional pattern list, ending at the first NUL.
candidate &[u8] Candidate bytes, ending at the first NUL.
limits Limits Finite input, pattern and output budgets.
returns Result<usize, GlobError> The first matching one-based pattern index, or zero when no pattern matches.

fn glob_expr

source

pub fn glob_expr(value: &[u8], list: Option<&[u8]>, limits: Limits) -> Result<Vec<u8>, GlobError>

Build a SQL expression from trusted SQL and Fossil patterns, with native quote advancement. The caller MUST supply a trusted SQL value expression. Only pattern apostrophes are escaped; value is neither quoted nor sanitized. Never pass untrusted SQL. Use a trusted column or parameter expression such as b"?1" and bind candidate bytes separately when executing the result through a caller-owned SQL interface.

This function executes no SQL. All input slices end at their first NUL.

Empty, absent and delimiter-only lists return b"0"; a quoted empty pattern produces a real GLOB term. Adjacent text after a closing quote can therefore differ from glob_create and glob_multi_match parsing.

Errors

Returns GlobError::Limit when list bytes, pattern count or expression bytes exceed their budgets, GlobError::Overflow for output capacity arithmetic, or GlobError::Allocation when reservation fails.

Examples

use gossil::glob::{glob_expr, Limits};
let limits = Limits { list_bytes: 64, candidate_bytes: 64,
                      patterns: 8, expression_bytes: 256 };
// Bind the candidate separately when executing this trusted parameter expression.
assert_eq!(glob_expr(b"?1", Some(b"*.rs"), limits)?, b"(?1 GLOB '*.rs')");
assert_eq!(glob_expr(b"?1", None, limits)?, b"0");
Parameter Type Description
value &[u8] Trusted SQL expression, neither quoted nor sanitized.
list Option<&[u8]> Optional pattern list, ending at the first NUL.
limits Limits Finite input, pattern and expression budgets.
returns Result<Vec<u8>, GlobError> SQL expression bytes, or b"0" when the list has no patterns.
