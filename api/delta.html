delta

Create and apply bounded Fossil deltas; application leaves checksum verification disabled.

Validation finishes before output allocation. A second pass copies checked slices.

enum DeltaError

source

pub enum DeltaError

A malformed delta, unsupported input size, or recoverable allocation failure.

Variant Description
MissingHeaderNewline Header digits were not followed by LF.
InputTooLarge { input: &'static str, length: usize } Input lies outside the reference signed-length envelope.
OutputTooLarge { advertised: u32, limit: u32 } Advertised size exceeds the effective ceiling.
TruncatedCommand { at: usize } A numeric command has no following operator.
MissingCopyComma { at: usize } Copy offset lacks a present comma delimiter.
UnknownOperator { at: usize, byte: u8 } Operator byte has no defined meaning.
SourceRange { offset: u32, count: u32, source_len: usize } Copy extends beyond source, including a zero copy beyond its end.
OutputRange { produced: u64, count: u32, advertised: u32 } Command would exceed advertised output.
TruncatedLiteral { at: usize, count: u32, remaining: usize } Literal has fewer bytes than its count.
Unterminated End or command-start NUL occurred before semicolon.
SizeMismatch { advertised: u32, produced: u64 } Semicolon arrived before advertised size was produced.
EncoderAllocationFailed { .. } Encoder storage reservation failed, preserving its stage and cause.
AllocationFailed { requested: usize, source: TryReserveError } Output reservation failed, preserving the genuine allocator cause.

Implements Debug, Display, Error.

fn output_size

pub fn output_size(delta: &[u8]) -> Result<u32, DeltaError>

Parse the advertised size without validating commands or applying an output limit.

Errors

Returns DeltaError::MissingHeaderNewline when digits are not followed by LF.

Examples

assert_eq!(gossil::delta::output_size(b"3\n" ).unwrap(), 3);
Parameter Type Description
delta &[u8] Encoded delta bytes.
returns Result<u32, DeltaError> The wrapped unsigned header value.

fn apply

source

pub fn apply(source: &[u8], delta: &[u8], limits: Limits) -> Result<Vec<u8>, DeltaError>

Apply a Fossil delta with checksum verification disabled, as in the pinned reference.

Errors

Returns a typed DeltaError for malformed commands, limits or reservation failure. Every command is validated before reserving output storage.

Examples

use gossil::delta::{apply, Limits};
assert_eq!(apply(b"", b"1\n1:A0;", Limits::default()).unwrap(), b"A");
Parameter Type Description
source &[u8] Original bytes available to copy commands.
delta &[u8] Header, copy/literal commands and semicolon terminator.
limits Limits Caller’s explicit output ceiling.
returns Result<Vec<u8>, DeltaError> Exactly the advertised output, with no trailing NUL.

fn create

source

pub fn create(source: &[u8], target: &[u8]) -> Result<Vec<u8>, DeltaError>

Create a Fossil delta using the selected reference build’s signed-char hash.

Errors

Returns input-length or causal allocation failures. Inputs are bounded by i32::MAX; integer digit counting above 2^30 is safe Rust policy, since the reference’s signed shifts there are undefined.

Examples

assert_eq!(gossil::delta::create(b"", b"").unwrap(), b"0\n0:0;");
Parameter Type Description
source &[u8] Original bytes available to copy commands.
target &[u8] Exact desired output bytes.
returns Result<Vec<u8>, DeltaError> Header, literal/copy commands and unsigned wrapping checksum, without a NUL.
