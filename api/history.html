history

Find shortest paths and common ancestors in an explicit check-in graph, as Fossil does. Port the check-in graph searches of Fossil src/path.c and src/pqueue.c, with finite bounds.

The original code is copyright 2011 D. Richard Hipp, under the 2-Clause BSD license. The license text is in tests/fixtures/history/fossil-license.txt.

The module ports path_shortest, path_common_ancestor and the queue order of pqueue.c from Fossil check-in 7e8ecf0ce4, over rows that the caller supplies. It neither reads a repository nor grants authority to derived indexes. Callers supply the query order of the plink and cherrypick rows, and the resolved metadata of branch and time. The algorithms keep the tie order of pqueue.c, and the native ban on a backwards step after a forward edge. The bounds and the errors for malformed input are new controls.

Recommendations

Use explicit finite limits, and keep the native query order of the rows. Next, qualify a separately authorized storage adapter before using persisted rows.

struct Checkin

pub struct Checkin<'a>

A Checkin holds one check-in with resolved metadata.

The caller resolves the default branch and the default for a missing time.

Field Type Description
rid i32 Positive native record identifier.
branch &'a [u8] Resolved branch_of_rid value, without an embedded NUL.
mtime f64 Finite Julian-day value of mtime_of_rid. The native default for a missing time is zero.

Implements Clone, Copy, Debug.

enum Direction

source

pub enum Direction

A Direction of search matches one of the native oneWayOnly values 0, 1 and 2.

Variant Description
Both Permit backwards steps only until the first forward step.
Forward Search from parent to child only.
ForwardWithCherrypicks Search forward, and also follow a non-excluded cherrypick from the initial node only.

Implements Clone, Copy, Debug, Eq, PartialEq.

enum Error

source

pub enum Error

An Error reports a failure of the graph, the input or a search.

A search that finds no path succeeds with None.

Variant Description
Limit A finite input or search budget was exceeded.
InvalidGraph The input has a duplicate, nonpositive or unknown identifier (also in hidden) or bad metadata, or a search met a cyclic predecessor chain. Cyclic rows are accepted.
NonFiniteCost A finite time difference or accumulated cost overflowed.
Allocation(TryReserveError) A checked allocation failed. The variant keeps the original cause of the reservation.

Implements Debug, Display, Error.

Graph::shortest

source

pub fn shortest(&self, from: i32, to: i32, options: Options<'_>) -> Result<Option<Path>, Error>

Port path_shortest, including hidden-node accounting and first-hop cherrypicks.

Errors

Returns input, finite-cost, allocation or search-budget failures.

Examples
use gossil::history::{Checkin, Direction, Graph, Limits, Options, ParentLink};

let nodes: Vec<_> = (1..=3)
    .map(|rid| Checkin { rid, branch: b"trunk", mtime: 0.0 })
    .collect();
let links = [
    ParentLink { parent: 1, child: 2, primary: true },
    ParentLink { parent: 2, child: 3, primary: true },
];
let limits = Limits {
    checkins: 3,
    links: 2,
    branch_bytes: 15,
    search_nodes: 16,
    row_visits: 16,
};
let graph = Graph::new(&nodes, &links, &[], limits)?;
let options = Options {
    primary_only: false,
    direction: Direction::Both,
    hidden: &[],
    branch_cost: 0,
};
let path = graph.shortest(3, 1, options)?.expect("a path");
let rids: Vec<_> = path.steps.iter().map(|s| s.rid).collect();
assert_eq!(rids, [3, 2, 1]);
assert_eq!(path.cost, 3.0);
Parameter Type Description
from i32 Starting check-in ID.
to i32 Destination check-in ID.
options Options<'_> Native path flags and hidden-node set.
returns Result<Option<Path>, Error> Ordered path, or none if the native search finds no path.

Graph::common_ancestor

source

pub fn common_ancestor(&self, me: i32, you: i32) -> Result<Option<Ancestor>, Error>

Port the two-front native path_common_ancestor search and path rewiring.

Errors

Returns input, allocation or search-budget failures.

Examples
use gossil::history::{Checkin, Graph, Limits, ParentLink};

let nodes: Vec<_> = (1..=3)
    .map(|rid| Checkin { rid, branch: b"trunk", mtime: 0.0 })
    .collect();
// Check-ins 2 and 3 are both children of check-in 1.
let links = [
    ParentLink { parent: 1, child: 2, primary: true },
    ParentLink { parent: 1, child: 3, primary: true },
];
let limits = Limits {
    checkins: 3,
    links: 2,
    branch_bytes: 15,
    search_nodes: 16,
    row_visits: 16,
};
let graph = Graph::new(&nodes, &links, &[], limits)?;
let ancestor = graph.common_ancestor(2, 3)?.expect("an ancestor");
assert_eq!(ancestor.pivot, 1);
assert!(graph.common_ancestor(0, 3)?.is_none());
Parameter Type Description
me i32 First endpoint. Zero means no ancestor, as in native Fossil.
you i32 Second endpoint. Zero means no ancestor.
returns Result<Option<Ancestor>, Error> Closest shared ancestor by native queue order, with its diagnostic path. Equal positive endpoints return the one-element path without stale global state.
