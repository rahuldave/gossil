gest_ticket

Emit the bounded bytes of artifact and project creation tickets through the shared Gest ticket emitter. Emit bounded Fossil ticket creation bytes for Gest artifact and project records.

See the Gest ticket guide for the format, caller responsibilities and a library example.

One shared emitter writes the creation artifact of every Gest kind. Each kind gives only its sorted field list and its gossil_kind value, so the task emitter in crate::task_ticket and the two emitters here write the same card syntax, size plan and checksum.

The card order and the construction of tokens and the checksum follow Fossil tkt.c:1837-1874 (b3a1c8efb2731dffbd5cc38c58ac349746de6da6). Fossil is Copyright D. Richard Hipp and contributors. Its BSD two-clause license is preserved in the frozen source evidence. This module performs no storage, identity generation or admission.

pub enum TicketError

Failure to validate the native ticket identity or bound output construction.

Variant Description
TicketId The K card ticket identity must contain exactly forty lowercase ASCII hexadecimal bytes.
Size Encoded output exceeds the caller’s bound or vector capacity.
Allocation(TryReserveError) Fallible output reservation failed.
Token(crate::token_codec::TokenError) Fossil token codec failed.
Json(serde_json::Error) JSON model value serialization failed.

Implements Debug, Display, Error.

fn artifact_creation_bytes

source

pub fn artifact_creation_bytes(
    artifact: &ArtifactValues,
    ticket_id: &[u8],
    actor: &[u8],
    date: NativeDate,
    max_output: usize,
) -> Result<Vec<u8>, TicketError>

Emit complete uncompressed Fossil ticket artifact bytes for a validated artifact creation.

A Gest artifact is a document record, such as a spec or a plan. It is not a Fossil blob. The contract CHANGE-01 uses an artifact ticket as the carrier of a logical change. The ticket becomes a change only when a validated logical_change declaration is attached at its K. This emitter writes no declaration, and metadata alone never declares a change.

The eight model fields are archived_at, body, created_at, gest_id, metadata, project_id, title and updated_at. Each uses JSON followed by native token escaping. The three fixed fields are gossil_deleted=false, raw gossil_kind=artifact and raw gossil_schema=1. The eleven J fields are sorted by name. The body keeps its exact text. A non-null archived_at does not mark the record as deleted.

The K, U and D cards and max_output follow crate::task_ticket::task_creation_bytes.

Examples

use gossil::gest_artifact_values::{ArtifactValueInputs, artifact_from_values};
use gossil::gest_ticket::artifact_creation_bytes;
use gossil::native_date::NativeDate;
use serde_json::json;

let artifact = artifact_from_values(ArtifactValueInputs {
    gest_id: json!("zyxwvutsrqponmlkzyxwvutsrqponmlk"),
    project_id: json!("kkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkk"),
    title: json!("Plan"),
    body: json!("Complete body"),
    metadata: json!({}),
    archived_at: json!(null),
    created_at: json!("2026-11-18T12:00:00Z"),
    updated_at: json!("2026-11-18T12:00:00Z"),
})
.unwrap();
let date = NativeDate::parse(b"2026-11-18T12:00:00Z").unwrap();
let bytes = artifact_creation_bytes(&artifact,
    b"0123456789abcdef0123456789abcdef01234567", b"actor", date, 65_536).unwrap();
assert!(bytes.windows(23).any(|w| w == b"J gossil_kind artifact\n"));

Errors

Returns an error for malformed K, byte limits, allocation, token encoding or JSON serialization failure.

Parameter Type Description
artifact &ArtifactValues Complete validated artifact snapshot.
ticket_id &[u8] Independent ticket identity bytes for the K card.
actor &[u8] Actor bytes for the U card.
date NativeDate Validated creation instant for the D card.
max_output usize Maximum complete encoded artifact length in bytes.
returns Result<Vec<u8>, TicketError> Complete uncompressed creation artifact bytes.

fn project_creation_bytes

pub fn project_creation_bytes(
    project: &ProjectValues,
    ticket_id: &[u8],
    actor: &[u8],
    date: NativeDate,
    max_output: usize,
) -> Result<Vec<u8>, TicketError>

Emit complete uncompressed Fossil ticket artifact bytes for a validated project creation.

The four model fields are archived_at, created_at, gest_id and updated_at. Each uses JSON followed by native token escaping. The three fixed fields are gossil_deleted=false, raw gossil_kind=project and raw gossil_schema=1. The seven J fields are sorted by name. The local checkout root is not a canonical field, so the ticket does not include its path. A non-null archived_at does not mark the record as deleted.

The K, U and D cards and max_output follow crate::task_ticket::task_creation_bytes.

Examples

use gossil::gest_project_values::{ProjectValueInputs, project_from_values};
use gossil::gest_ticket::project_creation_bytes;
use gossil::native_date::NativeDate;
use serde_json::json;

let project = project_from_values(ProjectValueInputs {
    gest_id: json!("kkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkk"),
    archived_at: json!(null),
    created_at: json!("2026-11-18T12:00:00Z"),
    updated_at: json!("2026-11-18T12:00:00Z"),
})
.unwrap();
let date = NativeDate::parse(b"2026-11-18T12:00:00Z").unwrap();
let bytes = project_creation_bytes(&project,
    b"0123456789abcdef0123456789abcdef01234567", b"actor", date, 65_536).unwrap();
assert!(bytes.starts_with(b"D 2026-11-18T12:00:00.000000000\nJ archived_at null\n"));
