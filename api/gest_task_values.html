gest_task_values

Convert independently admitted Gest task fields into validated owned values. Convert complete, already decoded task fields without storage or raw JSON parsing.

Callers own contributor admission, field presence, unknown-field classification, duplicate lexemes, byte budgets and whole-history validation. This module does not admit migration or implement the Gest API.

task_from_values validates the eleven explicit TaskValueInputs fields. task_to_values recovers them from the private TaskValues record with canonical status spelling and UTC timestamp strings. Business timestamps use chrono 0.4.44 parsing, then reject normalized output that cannot be parsed again. They do not use the artifact D-card grammar or impose timestamp ordering.

struct TaskValueInputs

source

pub struct TaskValueInputs

All eleven owned model fields, with explicit nulls for nullable fields.

Callers assemble every field after raw input admission. No fields default. A null Value is data for metadata and marks absence for nullable fields. Validate this input with task_from_values before using it as a task record.

Field Type Description
gest_id Value Task identifier of exactly 32 lowercase k through z letters, upstream id.
project_id Value Project identifier of exactly 32 lowercase k through z letters.
title Value Exact title string, including empty strings and Unicode.
priority Value Null or a JSON integer from 0 through 255, without named priority labels.
status Value Case-insensitive open, in-progress, in_progress, inprogress, done or cancelled.
description Value Exact description string.
assigned_to Value Null or an author identifier of exactly 32 lowercase k through z letters.
metadata Value Any JSON value, including null.
resolved_at Value RFC3339 string for done or cancelled, otherwise null.
created_at Value RFC3339 creation string whose normalized UTC output must parse again.
updated_at Value RFC3339 modification string whose normalized UTC output must parse again.

Implements Clone, Debug, PartialEq.

struct TaskValues

source

pub struct TaskValues

Validated task data whose private fields prevent unchecked construction.

Use task_from_values to construct a record and task_to_values to read every field as an owned Value. Cloning a record preserves its validation.

Implements Clone, Debug, PartialEq.

struct TaskValueError

source

pub struct TaskValueError

Report one field’s type, value or terminal-status validation failure.

Its fmt::Display output names the field and reason without echoing input. The converter returns the first failure in its validation order. Self::parse_cause returns the original timestamp parser error. Equality includes that cause, so errors with equal display text can compare unequal.

Implements Clone, Debug, Eq, PartialEq, Display, Error.

TaskValueError::parse_cause

source

pub fn parse_cause(&self) -> Option<&chrono::ParseError>

Inspect the typed chrono cause without exposing the supplied timestamp.

Parameter Type Description
returns Option<&chrono::ParseError> The actual parser error for input or canonical UTC output parsing, or None for validation failures that did not come from the parser. Chrono’s alloc-only build does not implement std::error::Error for chrono::ParseError, so this accessor supplies the cause instead of std::error::Error::source.

fn task_from_values

source

pub fn task_from_values(fields: TaskValueInputs) -> Result<TaskValues, TaskValueError>

Validate and own complete task fields using the adopted Gest value contract.

Returns

A privately constructed record, or the first invalid field. Numeric priority uses checked u8 conversion rather than upstream SQL’s wrapping cast. The adopted Gossil contract additionally requires terminal/resolution pairing and a normalized UTC representation accepted by the RFC3339 parser.

This function performs no reference lookup, clock read, ID generation, raw JSON admission, SQL operation or complete-history validation.

Errors

Returns TaskValueError for a non-string value in a string field, an invalid full identifier, a priority other than null or an integer from 0 through 255, or an unknown status. Timestamp strings must parse with chrono 0.4.44 and their normalized UTC output must parse again. resolved_at must be a valid timestamp for done or cancelled and null for open or in-progress. Metadata accepts every Value variant. Title and description have no content restrictions, and timestamps have no ordering constraint.

Examples

use gossil::gest_task_values::{TaskValueInputs, task_from_values, task_to_values};
use serde_json::json;

let fields = TaskValueInputs {
    gest_id: json!("zyxwvutsrqponmlkzyxwvutsrqponmlk"),
    project_id: json!("kkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkk"),
    title: json!("Review task values"),
    priority: json!(255),
    status: json!("IN_PROGRESS"),
    description: json!(""),
    assigned_to: json!(null),
    metadata: json!([null, {"reviewed": false}]),
    resolved_at: json!(null),
    created_at: json!("2026-11-18T07:00:00-05:00"),
    updated_at: json!("2026-11-18T12:00:00Z"),
};
let task = task_from_values(fields).unwrap();
let values = task_to_values(&task);
assert_eq!(values.status, json!("in-progress"));
assert_eq!(values.created_at, json!("2026-11-18T12:00:00+00:00"));
assert_eq!(task_from_values(values).unwrap(), task);
Parameter Type Description
fields TaskValueInputs Independently admitted decoded values for every model field.
returns Result<TaskValues, TaskValueError> A privately constructed record, or the first invalid field. Numeric priority uses checked u8 conversion rather than upstream SQL’s wrapping cast. The adopted Gossil contract additionally requires terminal/resolution pairing and a normalized UTC representation accepted by the RFC3339 parser.

fn task_to_values

source

pub fn task_to_values(task: &TaskValues) -> TaskValueInputs

Return every model field with canonical status and UTC timestamp strings.

Parameter Type Description
task &TaskValues A record validated by [task_from_values].
returns TaskValueInputs Eleven explicit owned values. Nullable fields stay null, metadata retains its JSON value semantics, and RFC3339 output has at most nine fractional digits. The UTC offset is +00:00. Output can be passed to task_from_values again; its example shows both functions together. The returned fields can be changed independently without changing the validated record.
