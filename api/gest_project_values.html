gest_project_values

Convert complete admitted canonical project fields into owned values. Complete owned conversion of the 4 canonical project fields.

Callers own raw admission, presence, unknown fields, budgets and history. Conversion performs no storage, reference lookup, clock read or ID generation.

struct ProjectValueInputs

source

pub struct ProjectValueInputs

Complete explicit input and output fields; null is supplied as a value.

Field Type Description
gest_id Value Full 32-letter identifier, called id upstream.
archived_at Value Explicit null or an RFC3339 archive timestamp.
created_at Value RFC3339 creation timestamp with canonical UTC output.
updated_at Value RFC3339 modification timestamp with canonical UTC output.

Implements Clone, Debug, PartialEq.

fn project_from_values

source

pub fn project_from_values(fields: ProjectValueInputs) -> Result<ProjectValues, ProjectValueError>

Validate every explicit decoded field into an owned project record.

Errors

Returns ProjectValueError for wrong types, invalid full IDs, invalid timestamps or UTC output outside the canonical RFC3339 domain. The local checkout root is excluded from this canonical record.

Parameter Type Description
fields ProjectValueInputs Complete model fields after caller-owned raw admission.
returns Result<ProjectValues, ProjectValueError> A privately validated record; timestamps normalize to UTC without ordering.
