compression

Pack and unpack Fossil blobs with bounded zlib operations. Pack and unpack Fossil’s four-byte big-endian capacity and zlib stream.

enum BlobError

source

pub enum BlobError

Report a packed-blob failure, retaining allocation and backend causes.

Variant Description
Level Compression level is outside zlib’s -1 or 0 through 9 range.
InputSize Input length cannot fit the format’s unsigned 32-bit header.
Limit Declared output capacity exceeds the caller’s resource limit.
Capacity Output exceeds its declared capacity.
Truncated The zlib stream ended before its checksum/end marker.
Allocation(TryReserveError) The allocator could not reserve the requested output storage.
Compress(flate2::CompressError) The compression backend rejected the input.
Decompress(flate2::DecompressError) The decompression backend rejected the stream or its checksum.

Implements Debug, Display, Error.

enum Unpacked

source

pub enum Unpacked

A short-input no-op is distinct from a successfully decoded empty blob.

Variant Description
NoPayload Fossil leaves the caller’s output unchanged for inputs of at most four bytes.
Bytes(Vec<u8>) Return decoded bytes from a complete validated zlib stream, possibly empty.

Implements Debug, PartialEq, Eq.

fn pack

source

pub fn pack(input: &[u8], level: i32) -> Result<Vec<u8>, BlobError>

Pack one byte slice with zlib’s default level or a level from zero to nine.

Errors

Rejects invalid levels, lengths above u32, allocation and backend failures.

Examples

let packed = gossil::compression::pack(b"abc", -1).unwrap();
assert_eq!(&packed[..4], &[0, 0, 0, 3]);
Parameter Type Description
input &[u8] Bytes to compress.
level i32 -1 selects the default, zero stores bytes, 1 through 9 compress.
returns Result<Vec<u8>, BlobError> A four-byte capacity header followed by a zlib stream.

fn pack_bounded

source

pub fn pack_bounded(input: &[u8], level: i32, max_stored: usize) -> Result<Vec<u8>, BlobError>

Pack bytes within a caller-selected stored-envelope ceiling.

The ceiling includes the four-byte header and is checked before every output reservation. The encoder still uses its fixed 8192-byte working buffer and the compression backend owns internal state; this is not a global allocator cap.

Examples

let packed = gossil::compression::pack_bounded(b"abc", -1, 64).unwrap();
assert_eq!(packed, gossil::compression::pack(b"abc", -1).unwrap());
assert!(gossil::compression::pack_bounded(b"abc", -1, 3).is_err());

Errors

Rejects output above the ceiling and preserves all ordinary packing errors.

Parameter Type Description
input &[u8] Full bytes to encode.
level i32 Native zlib level, -1 or zero through nine.
max_stored usize Largest returned header plus compressed stream.
returns Result<Vec<u8>, BlobError> Exact legacy packed bytes when they fit the ceiling.

pub fn pack_two(first: &[u8], second: &[u8]) -> Result<Vec<u8>, BlobError>

Pack the concatenation of two slices at Fossil’s fixed compression level nine.

Errors

Rejects lengths above u32, allocation and compression backend failures.

Examples

assert!(gossil::compression::pack_two(b"a", b"bc").is_ok());
Parameter Type Description
first &[u8] First bytes in the concatenation.
second &[u8] Remaining bytes in the concatenation.
returns Result<Vec<u8>, BlobError> A capacity header and zlib stream for the combined content.

fn unpack

source

pub fn unpack(input: &[u8], max_output: usize) -> Result<Unpacked, BlobError>

Decode one packed zlib stream within a caller-selected capacity ceiling.

The header is an upper bound, so shorter actual output is accepted. Like Fossil’s uncompress, trailing bytes after the first stream are ignored. A short input yields NoPayload; an in-place caller must retain its old bytes for that outcome. Invalid data produces an error, even though Fossil’s diagnostic test-uncompress command ignores the C function’s error return.

Errors

Rejects caller-limit violations, exceeded headers, invalid/truncated zlib, and allocation failures. No fixed small limit is a format restriction.

Examples

use gossil::compression::{pack, unpack, Unpacked};
assert_eq!(unpack(&pack(b"abc", -1).unwrap(), 3).unwrap(), Unpacked::Bytes(b"abc".to_vec()));
Parameter Type Description
input &[u8] Packed bytes including the capacity header.
max_output usize Maximum accepted declared capacity, checked before decoding.
returns Result<Unpacked, BlobError> No-change outcome or the validated decompressed bytes.
