gest_note_values

Convert complete admitted canonical note fields into owned values. Convert 7 explicit decoded note fields into owned validated records.

Callers own raw admission, field presence, unknown fields, budgets and history. Callers also check that the entity and the author exist, because that check needs other records. This module reads no clock and performs no storage, reference lookup or ID generation. chrono parses the two timestamps as RFC3339, and note_to_values returns them in canonical UTC.

struct NoteValueInputs

source

pub struct NoteValueInputs

Holds the complete owned input and output fields.

The caller must give every field explicitly, including a null author.

Field Type Description
gest_id Value Full note ID, called id upstream.
entity_id Value Full ID of the task, artifact or iteration that the note is attached to.
entity_type Value Kind of the entity: artifact, iteration or task, in any case.
author_id Value Full ID of the author, or JSON null when the author is unknown.
body Value Exact body text, including empty strings, Unicode and line endings.
created_at Value RFC3339 creation timestamp with representable canonical UTC output.
updated_at Value RFC3339 modification timestamp with representable canonical UTC output.

Implements Clone, Debug, PartialEq.

pub fn parse_cause(&self) -> Option<&chrono::ParseError>

Return the chrono parse error of a timestamp, without the supplied data.

Parameter Type Description
returns Option<&chrono::ParseError> The initial or canonical-output parse cause, or None for other failures. The alloc-only parser error of chrono does not implement std::error::Error.

fn note_from_values

source

pub fn note_from_values(fields: NoteValueInputs) -> Result<NoteValues, NoteValueError>

Validate every explicit decoded field and preserve the complete note value.

Errors

Returns NoteValueError for wrong types, invalid full IDs, an entity type other than artifact, iteration or task, invalid timestamp input or UTC output outside the canonical RFC3339 domain.

Examples

use gossil::gest_note_values::{NoteValueInputs, note_from_values, note_to_values};
use serde_json::json;

let fields = NoteValueInputs {
    gest_id: json!("klmnopqrstuvwxyzklmnopqrstuvwxyz"),
    entity_id: json!("zyxwvutsrqponmlkzyxwvutsrqponmlk"),
    entity_type: json!("Task"),
    author_id: json!(null),
    body: json!("Checked the *build*.\n"),
    created_at: json!("2026-11-18T07:00:00-05:00"),
    updated_at: json!("2026-11-18T12:00:00Z"),
};
let record = note_from_values(fields).unwrap();
let output = note_to_values(&record);
assert_eq!(output.entity_type, json!("task"));
assert_eq!(output.author_id, json!(null));
assert_eq!(output.created_at, json!("2026-11-18T12:00:00+00:00"));
assert_eq!(note_from_values(output).unwrap(), record);
Parameter Type Description
fields NoteValueInputs Complete fields admitted by the caller before this conversion.
returns Result<NoteValues, NoteValueError> An owned validated record with private fields. The body keeps its exact bytes, a null author stays null, and the entity type takes its lowercase spelling. The conversion imposes no order on the timestamps.

fn note_to_values

source

pub fn note_to_values(record: &NoteValues) -> NoteValueInputs

Return all 7 fields as independent owned values.

Parameter Type Description
record &NoteValues A record validated by [note_from_values].
returns NoteValueInputs Complete model values with UTC RFC3339 timestamp strings and an explicit JSON null for an unknown author. UTC uses +00:00 and at most nine fractional digits. Output can be validated again, and a change to the output does not change the record.
