gossil

Supply inherited-test tools, bounded byte primitives, local storage and decoded task values.
Name Summary

fn parse_report

source

pub fn parse_report(text: &str) -> Report

Parse exact Fossil driver output.

Every final-summary occurrence counts, even if its numeric fields are invalid. Nonnumeric or overflowing counts and duplicate summaries permanently mark the report malformed. Call validate_report before accepting it.

Examples

let report = gossil::parse_report("test example OK\n***** Final results: 0 errors out of 1 tests\n");
assert_eq!(report.assertions[0].name, "example");
assert!(gossil::validate_report(&report, Some(0)).is_ok());
Parameter Type Description
text &str Captured process output.
returns Report Individual results and totals, requiring separate validation.

fn validate_report

source

pub fn validate_report(report: &Report, exit_code: Option<i32>) -> Result<(), RunnerError>

Validate execution, real assertions and exact count reconciliation.

Errors

Returns RunnerError::Invalid for a nonzero or absent exit code, malformed output, missing or inconsistent counts, skips, failed assertions or no real assertion.

Examples

let report = gossil::parse_report("Ok\n");
assert!(gossil::validate_report(&report, Some(0)).is_err());
Parameter Type Description
report &Report Parsed assertions and totals.
exit_code Option<i32> Actual process exit status, absent for a signal.
returns Result<(), RunnerError> Success only when real assertions pass and all totals reconcile.

fn execute

source

pub fn execute(config: Config) -> Result<Run, RunnerError>

Run one inherited suite in fresh scratch storage and persist report.json.

Errors

Returns RunnerError::Invalid for invalid configuration or unsafe process ownership, RunnerError::NotExecutable for an unsuitable executable, RunnerError::Io for filesystem or process failures, or RunnerError::Json for serialization failures. A rejected suite normally returns a Run with accepted set to false.

Examples

let config: gossil::Config = serde_json::from_slice(&std::fs::read("CONFIG.json")?)?;
let run = gossil::execute(config)?;
println!("accepted: {}", run.accepted);
Parameter Type Description
config Config Explicit inputs and owned output directory.
returns Result<Run, RunnerError> Recorded results, including failed suites; setup failures return an error.
