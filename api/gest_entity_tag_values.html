gest_entity_tag_values

Convert complete admitted canonical entity_tag join fields into owned values. Convert 4 explicit decoded entity_tag fields into owned validated records.

An entity_tag row attaches one tag to one task, artifact or iteration. It has no Gest ID of its own. Its key is the tuple of entity type, entity ID and tag ID.

Callers own raw admission, field presence, unknown fields, budgets and history. Callers also own the key, the association incarnation and its lifecycle, and the check that the entity and the tag exist. Each of those needs other records. This module reads no clock and performs no storage, reference lookup or ID generation. chrono parses the timestamp as RFC3339, and entity_tag_to_values returns it in canonical UTC.

struct EntityTagValueInputs

source

pub struct EntityTagValueInputs

Holds the complete owned input and output fields.

The caller must give every field explicitly. The row has no gest_id.

Field Type Description
entity_id Value Full ID of the tagged task, artifact or iteration.
entity_type Value Kind of the tagged entity, one of artifact, iteration or task in any case.
tag_id Value Full ID of the attached tag.
created_at Value RFC3339 attachment timestamp with representable canonical UTC output.

Implements Clone, Debug, PartialEq.

fn entity_tag_from_values

source

pub fn entity_tag_from_values(
    fields: EntityTagValueInputs,
) -> Result<EntityTagValues, EntityTagValueError>

Validate every explicit decoded field and preserve the complete entity_tag value.

Errors

Returns EntityTagValueError for wrong types, invalid full IDs, an entity type other than artifact, iteration or task, invalid timestamp input or UTC output outside the canonical RFC3339 domain.

Examples

use gossil::gest_entity_tag_values::{
    EntityTagValueInputs, entity_tag_from_values, entity_tag_to_values,
};
use serde_json::json;

let fields = EntityTagValueInputs {
    entity_id: json!("zyxwvutsrqponmlkzyxwvutsrqponmlk"),
    entity_type: json!("Artifact"),
    tag_id: json!("klmnopqrstuvwxyzklmnopqrstuvwxyz"),
    created_at: json!("2026-11-18T07:00:00-05:00"),
};
let record = entity_tag_from_values(fields).unwrap();
let output = entity_tag_to_values(&record);
assert_eq!(output.entity_type, json!("artifact"));
assert_eq!(output.created_at, json!("2026-11-18T12:00:00+00:00"));
assert_eq!(entity_tag_from_values(output).unwrap(), record);
Parameter Type Description
fields EntityTagValueInputs Complete fields admitted by the caller before this conversion.
returns Result<EntityTagValues, EntityTagValueError> An owned validated record with private fields. The entity type takes its lowercase spelling, so two inputs that differ only in the case of the entity type give equal records and the same key tuple.

pub fn entity_tag_to_values(record: &EntityTagValues) -> EntityTagValueInputs

Return all 4 fields as independent owned values.

Parameter Type Description
record &EntityTagValues A record validated by [entity_tag_from_values].
returns EntityTagValueInputs Complete model values with the lowercase entity type and a UTC RFC3339 timestamp string. UTC uses +00:00 and at most nine fractional digits. Output can be validated again, and a change to the output does not change the record.
