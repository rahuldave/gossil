artifact

Represent a project document, such as a spec or an ADR. The artifacts table: a project’s documents, such as specs and ADRs.

Model is one row. New, Patch and Filter carry the input of a create, an update and a list. Ported from src/store/model/artifact.rs at the Gest pin.

struct Model

source

pub struct Model

A persistent document within a project, such as a spec, an ADR or a design document.

Implements Clone, Debug, Deserialize<'de>, Eq, PartialEq, Serialize, From<ArtifactValues>.

pub struct Filter

Criteria for filtering artifacts.

Field Type Description
all bool Include archived artifacts alongside active ones.
only_archived bool Restrict results to archived artifacts only.
tag Option<String> Restrict to artifacts carrying this tag label.
