project

Represent a tracked project. The projects table: each repository or directory root that Gest tracks.

Ported from src/store/model/project.rs at the Gest pin. The canonical project record of crate::gest_project_values has no root, because the root is a local checkout binding (GEST-01). So this module has no From for that record. A caller that holds the root uses Model::from_synced_parts.

struct Model

source

pub struct Model

A project represents a tracked repository or directory root.

Each project is uniquely identified by its root path and is assigned a stable Id at creation time.

Implements Clone, Debug, Deserialize<'de>, Eq, PartialEq, Serialize.

Model::from_synced_parts

pub fn from_synced_parts(
    id: Id,
    root: PathBuf,
    archived_at: Option<DateTime<Utc>>,
    created_at: DateTime<Utc>,
    updated_at: DateTime<Utc>,
) -> Self

Reconstruct a project from a synced .gest/project.yaml file.

The id and timestamps come from the synced file (so collaborators share a stable identity), while root is the local checkout path.

Parameter Type Description
id Id the id from the synced file
root PathBuf the local checkout path
archived_at Option<DateTime<Utc>> when the project was archived, or None if it is active
created_at DateTime<Utc> when the project was first registered
updated_at DateTime<Utc> when the project record last changed
returns Self The project, built from these parts with no checks.

pub fn new(root: PathBuf) -> Self

Create a new project with a fresh Id and timestamps set to now.

Panics

Panics when the system clock is before 1970 or the operating system gives no random bytes, as upstream does.

Parameter Type Description
root PathBuf the path of the project root
returns Self The project, active (not archived) and not yet saved.
