gest_model

Hold the Gest domain model and its primitive values, copied from the pinned Gest source. The Gest domain model, with one record type for each Gest entity and the primitive values that they use.

This module ports src/store/model of Gest at commit eaf821b19c3cf75b99d22e1cc70e0eff4a3562a8, under the MIT licence in src/gest_model/gest-LICENSE.txt. Each submodule keeps the upstream name of its Model struct and of its New, Patch and Filter inputs.

The port differs from upstream in these ways:

  • There is no TryFrom<libsql::Row>. Gossil does not store Gest SQL rows. A model comes from a record that a converter in crate::gest_*_values has validated, through From, so the converters stay the one place that checks a decoded field. The models also derive Deserialize, as upstream does.
  • The project_workspace and transaction models are not here. They are local bookkeeping, and the storage tasks own them.
  • Getters are written by hand, with the names and return types that the getset derives give upstream.
  • The clock comes from std::time::SystemTime, as chrono::Utc::now does, so chrono needs no clock feature.
Name Summary
artifact Represent a project document, such as a spec or an ADR. The artifacts table: a project’s documents, such as specs and ADRs.
author Represent the humans and agents who write notes and other records. The authors table: the humans and agents who create notes, events and other records.
entity_tag Represent the attachment of a tag to a task, an artifact or an iteration. The entity_tags join table, which attaches a tag to a task, an artifact or an iteration.
iteration Represent a time-boxed group of tasks. The iterations table: time-boxed groups of tasks within a project.
note Represent a note attached to an entity. The notes table: notes attached to an entity, each with an optional author.
primitives Hold the primitive values that the Gest records use.
project Represent a tracked project. The projects table: each repository or directory root that Gest tracks.
relationship Represent a directed link between two entities. The relationships table: directed links, such as blocks or child-of, between two entities.
tag Represent a label that is stored once and attached to entities. The tags table: labels, stored once each, that the entity_tags table attaches to entities.
task Represent a unit of work within a project. The tasks table: units of work within a project.
