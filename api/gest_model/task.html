task

Represent a unit of work within a project. The tasks table: units of work within a project.

Model is one row. New, Patch and Filter carry the input of a create, an update and a list. Ported from src/store/model/task.rs at the Gest pin.

struct New

source

pub struct New

Parameters for creating a new task.

Field Type Description
assigned_to Option<Id> Author the new task should be assigned to.
description String Longer-form description of the work required.
metadata Option<Value> Optional user-defined metadata merged into the new row.
priority Option<u8> Optional priority score. Lower numbers rank first.
status Option<TaskStatus> Initial lifecycle status. When unset, it defaults to TaskStatus::default.
title String Short human-readable title.

Implements Clone, Debug, Default, Deserialize<'de>, Serialize.

struct Patch

source

pub struct Patch

Optional fields for updating an existing task.

Field Type Description
assigned_to Option<Option<Id>> Replacement assignee. Some(None) clears it.
description Option<String> Replacement description.
metadata Option<Value> Replacement metadata object. When set, it overwrites the stored value.
priority Option<Option<u8>> Replacement priority. Some(None) clears it.
status Option<TaskStatus> New lifecycle status. A transition to a terminal status also sets resolved_at.
title Option<String> Replacement title.

Implements Clone, Debug, Default, Deserialize<'de>, Serialize.

struct Filter

pub struct Filter

Criteria for filtering tasks.

Field Type Description
all bool Include tasks in every status, even terminal ones.
assigned_to Option<String> Restrict to tasks assigned to the author matching this name or id prefix.
status Option<TaskStatus> Restrict to tasks in this status.
tag Option<String> Restrict to tasks carrying this tag label.

Implements Clone, Debug, Default.
