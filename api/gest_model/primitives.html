primitives

Hold the primitive values that the Gest records use.

Ported from src/store/model/primitives.rs at the Gest pin. Each type is named Primitive in its own module and exported here under its domain name. The module is inline here, and not in its own file, because a file of declarations only has no line that the coverage report can count.

struct Id

source

pub struct Id(/* private field */);

A 128-bit identifier encoded as a 32-character string using the k-z alphabet.

Each byte is split into two nibbles and mapped through a reverse-hex alphabet, producing a lowercase, URL-safe string that sorts in reverse byte order. The encoding is bijective. Every valid 32-character [k-z] string decodes to exactly one [u8; 16], and each [u8; 16] encodes to exactly one such string.

Examples

let id = Id::new();
assert_eq!(id.to_string().len(), 32);

let parsed: Id = id.to_string().parse().unwrap();
assert_eq!(id, parsed);

Implements Clone, Debug, Eq, Hash, PartialEq, Serialize, Deserialize<'de>, Default, Display, From<Primitive>, FromStr, From<String>, From<&str>.

Id::validate_prefix

source

pub fn validate_prefix(s: &str) -> Result<&str, String>

Validate that s is a valid ID prefix of 1 to 32 characters, all in [k-z].

Errors

Rejects empty strings, strings longer than 32 bytes, and any character outside the ID alphabet. The error message says what is wrong.

Parameter Type Description
s &str the prefix to check
returns Result<&str, String> Returns Ok(s) on success so callers can chain the result.

enum Priority

source

pub enum Priority

Relative importance assigned to a task.

The five named levels map to 0..=4. The task model itself stores any u8 priority, so this enum is the named surface and not the only one (GEST-02).

Variant Description
Critical = 0 Must be addressed immediately. It blocks other work.
High = 1 Important but not a blocker.
Low = 3 Should be done eventually.
Lowest = 4 Nice to have. Defer it if needed.
Medium = 2 Default importance for most work.

Implements Clone, Copy, Debug, Deserialize<'de>, Eq, Hash, Ord, PartialEq, PartialOrd, Serialize, Display, From<Primitive>, FromStr, TryFrom<u8>.

pub enum RelationshipType

The type of relationship between two entities.

Variant Description
BlockedBy Source cannot progress until the target is resolved.
Blocks Source prevents the target from progressing.
ChildOf Source is a child of the target in a parent/child hierarchy.
ParentOf Source is a parent of the target in a parent/child hierarchy.
RelatesTo Symmetric, loose association between source and target.
