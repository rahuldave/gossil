tag

Represent a label that is stored once and attached to entities. The tags table: labels, stored once each, that the entity_tags table attaches to entities.

Ported from src/store/model/tag.rs at the Gest pin.

struct Model

source

pub struct Model

A deduplicated label that can be attached to any entity.

Implements Clone, Debug, Deserialize<'de>, Eq, PartialEq, Serialize, From<TagValues>.
