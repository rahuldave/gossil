diff

Compute bounded line edit scripts ported from Fossil’s src/diff.c.

This module supplies the normalized-byte line layer of text_diff. The callers must perform blob_to_utf8_no_bom conversion separately. Bytes need not be valid UTF-8. No BOM removal, UTF-16 conversion, token diff, renderer, regular expression filter, filesystem or repository access occurs here.

Derived from Fossil b3a1c8efb2731dffbd5cc38c58ac349746de6da6. Copyright (c) 2007 D. Richard Hipp. Distributed under the 2-Clause BSD license.

Recommendations

Normalize inputs before calling this layer and select finite caller limits.

pub enum Whitespace

Whitespace comparison used when hashing and comparing lines.

Variant Description
Exact Compare all bytes except the line terminator.
IgnoreEol Ignore Fossil’s trailing whitespace bytes (8, 9, 10, 12, 13, 32).
IgnoreAll Ignore Fossil’s whitespace bytes throughout each line.

struct LineDiffOptions

source

pub struct LineDiffOptions

Options supported by the raw, line-based portion of Fossil text_diff.

Field Type Description
whitespace Whitespace Select exact, trailing-space or all-space comparison.
strip_cr bool Remove a trailing carriage return, including on an unterminated line.
invert bool Exchange FROM and TO before computing the script.
optimize bool Apply native readability shifts (DIFF_NOOPT disables this).
not_too_big bool Reject scripts with more than 10,000 inserted plus deleted lines.

Implements Clone, Copy, Debug, PartialEq, Eq, Default.

enum DiffError

source

pub enum DiffError

Native rejection or a caller resource boundary.

Variant Description
Binary Embedded NUL or a line longer than 32767 bytes.
WhitespaceOnly Whitespace mode produced the native unchanged-script rejection.
TooManyChanges not_too_big rejected more than 10,000 changed lines.
Limit A caller bound, checked arithmetic or allocation failed.

Implements Clone, Copy, Debug, PartialEq, Eq.

fn line_diff

source

pub fn line_diff(
    from: &[u8],
    to: &[u8],
    options: LineDiffOptions,
    limits: DiffLimits,
) -> Result<Vec<Edit>, DiffError>

Compute native line COPY/DELETE/INSERT triples for normalized byte text.

The result includes the native terminating zero triple. LF is excluded from comparison, so adding or removing the final LF does not change a line. This API does not perform the BOM or UTF-16 conversion of blob_to_utf8_no_bom.

Errors

Returns DiffError::Binary for an embedded NUL or a line longer than 32,767 bytes. Returns DiffError::WhitespaceOnly when a whitespace mode produces one copy-only triple followed by the zero triple, and DiffError::TooManyChanges when not_too_big rejects more than 10,000 inserted plus deleted lines. Returns DiffError::Limit for caller bounds, fixed input caps, checked arithmetic or allocation failure. No partial script is returned on failure.

Examples

use gossil::diff::{line_diff, DiffLimits, Edit, LineDiffOptions};
let edits = line_diff(
    b"old\n", b"new\n", LineDiffOptions::default(), DiffLimits::default(),
).unwrap();
assert_eq!(edits, vec![
    Edit { copy: 0, delete: 1, insert: 1 },
    Edit::default(),
]);
Parameter Type Description
from &[u8] Already-normalized FROM bytes.
to &[u8] Already-normalized TO bytes.
options LineDiffOptions Supported line comparison and edit options.
limits DiffLimits Finite resource bounds for this invocation.
returns Result<Vec<Edit>, DiffError> Native triples ending in a zero triple.
