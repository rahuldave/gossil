git_reader

Read Git commits, refs and settings beside Git, read-only, through pinned gix crates. Read Git commits, refs and repository settings beside Git, and never write to Git.

This module is the only place in Gossil that uses the gix crates. It opens one Git worktree and reads what binding needs, by GIT-01 of the Git access contract. Binding is the step that ties a Gossil change to a Git commit. The module reads the Git directory and the common directory, HEAD and a branch tip. It also reads a commit with its ordered parents, the object format and three configuration keys.

The reader reads raw objects. It opens the object store with gix_odb::at_opts, with no replacement table and without multi-pack-index. So refs/replace never changes a result. It recomputes the hash of each commit that it reads, and it returns an error for a mismatch.

Each read has a finite limit from Limits. The reader itself reads HEAD, each ref, a .git file, commondir, each configuration file and each alternates file. It reads each one without blocking and within its limit. It parses a loose ref, HEAD and packed-refs itself, as Git does, and gives the bytes of the configuration and of a .git file to the gix parsers.

The reader refuses what the first release does not support, by GIT-04. It refuses a shallow clone, a reftable repository, an unknown object format, an unknown version-1 extension and a bare repository. It reads core.bare and core.worktree from the files that Git reads for the worktree. So a linked worktree of a bare repository opens, except when extensions.worktreeConfig makes the common core.bare apply to it. The reader makes these checks each time it opens a worktree.

The lint just lint bans the write paths of the gix crates (GIT-03). tests/git_reader.rs checks that a run of every call leaves the Git directories unchanged. tests/git_write_lint.rs checks that no other source file names a gix path.

Recommendations

Open a worktree for each registration, each locate and each bind, because a repository can change its format between two runs. Keep every new gix call in this module.

struct Limits

source

pub struct Limits

Limits sets the finite bound of each read. The type has no unbounded default.

Field Type Description
config_bytes u64 Maximum bytes of each configuration file, config or config.worktree.
small_file_bytes u64 Maximum bytes of HEAD, each loose ref, a .git file and commondir.
packed_refs_bytes u64 Maximum bytes of the packed-refs file.
symbolic_depth usize Maximum number of refs that one lookup reads, HEAD included. Git’s SYMREF_MAXDEPTH is five.
commit_bytes u64 Maximum bytes of one commit object, after decompression.
parents usize Maximum number of parents of one commit.
alternates_bytes u64 Maximum bytes of each objects/info/alternates file.
alternates usize Maximum number of alternate object directories, over all nested alternates files.

Implements Clone, Copy, Debug, PartialEq, Eq.

const Limits::STANDARD

source

const STANDARD: Limits = _;

STANDARD holds finite limits that fit ordinary repositories. They are 1 MiB of configuration, 4 KiB small files, 256 MiB of packed refs, depth 5 and 16 MiB commits. They also allow 1024 parents, and 64 KiB of alternates with 16 alternate directories.

GitObjectId::from_hex

source

pub fn from_hex(format: ObjectFormat, hex: &str) -> Result<Self, GitReadError>

Parse a full hexadecimal object ID of format, and refuse an abbreviated ID.

Errors

Returns GitReadError::InvalidObjectId for a wrong length or a non-hex digit.

Examples
use gossil::git_reader::{GitObjectId, GitReadError, ObjectFormat};

let hex = "4B825DC642CB6EB9A060E54BF8D69288FBEE4904";
let id = GitObjectId::from_hex(ObjectFormat::Sha1, hex).unwrap();
assert_eq!(id.as_bytes().len(), 20);
assert_eq!(id.to_string(), hex.to_ascii_lowercase());

// An abbreviated ID, or a SHA-1 ID read as SHA-256, is refused.
let short = GitObjectId::from_hex(ObjectFormat::Sha1, "4b825dc");
assert!(matches!(short, Err(GitReadError::InvalidObjectId { .. })));
let other = GitObjectId::from_hex(ObjectFormat::Sha256, hex);
assert!(matches!(other, Err(GitReadError::InvalidObjectId { .. })));
Parameter Type Description
format ObjectFormat Hash algorithm that the ID must have.
hex &str Exactly 40 or 64 hexadecimal digits, by format, in upper or lower case.
returns Result<Self, GitReadError> The parsed ID.

enum GitReadError

source

pub enum GitReadError

GitReadError names each reason why the reader refuses or fails, with what the user must know.

Variant Description
Io { path: PathBuf, cause: Cause } A file system call failed.
NotAWorktree { path: PathBuf } The folder has no .git entry and is not a Git directory.
NotARepository { path: PathBuf, cause: Cause } The .git entry does not lead to a valid Git directory.
Bare { path: PathBuf } The folder is a bare repository, which is not a location (SRC-09).
Shallow { common_dir: PathBuf } The repository is a shallow clone, which the first release refuses (P10).
Reftable { common_dir: PathBuf } The repository uses the reftable ref backend, which the first release refuses.
UnsupportedObjectFormat { value: Vec<u8> } extensions.objectFormat names a format other than sha1 or sha256.
UnsupportedRefStorage { value: Vec<u8> } extensions.refStorage names a backend other than files or reftable.
UnsupportedRepositoryVersion { version: i64 } core.repositoryformatversion is not 0 or 1, or is 0 with a version-1 extension.
ForeignWorktree { worktree: PathBuf, configured: PathBuf } core.worktree names a folder other than the opened one, so Git’s worktree is elsewhere.
UnsupportedExtension { name: String } Version 1 names an extension that the reader does not understand, which Git also refuses.
Config { path: PathBuf, cause: Cause } A configuration file or value could not be parsed.
TooLarge { what: String, size: u64, limit: u64 } A file or object is larger than its limit.
NotAFile { path: PathBuf, kind: &'static str } An entry that must be a regular file is a FIFO, a device, a socket, a folder, or a symbolic link that the reader does not follow.
Alternate { path: PathBuf, cause: Cause } An objects/info/alternates file names an alternate that the reader does not use, or the alternates changed after the open.
InvalidObjectId { text: String, format: ObjectFormat } A text is not a full object ID of the format.
FormatMismatch { id: GitObjectId, repository: ObjectFormat } An object ID has a format other than the format of the repository.
InvalidBranchName { name: String } A branch name does not make a valid full ref name.
Ref { name: Vec<u8>, cause: Cause } A ref could not be read or parsed.
SymbolicDepth { name: Vec<u8>, limit: usize } A chain of symbolic refs is deeper than the limit.
ObjectRead { id: GitObjectId, cause: Cause } The object store failed to read an object.
ObjectMissing { id: GitObjectId } No object with the ID is present, not even in an alternate (COMP-T06).
NotACommit { id: GitObjectId, kind: ObjectKind } The object exists, but it is not a commit.
HashMismatch { id: GitObjectId, computed: GitObjectId } The recomputed hash of the object differs from its ID.
MalformedCommit { id: GitObjectId, cause: Cause } The commit body could not be parsed up to its parents.
TooManyParents { id: GitObjectId, limit: usize } The commit has more parents than the limit.

Implements Clone, Debug, PartialEq, Eq, Display, Error.

GitRepository::open

source

pub fn open(worktree: &Path, limits: Limits) -> Result<Self, GitReadError>

Open the Git worktree whose top folder is worktree, and check that the first release supports it.

The folder must hold the .git entry itself. The reader searches no parent folder and reads no Git environment variable.

Errors

Returns one of these errors:

  • GitReadError::NotAWorktree for a folder without a .git entry.
  • GitReadError::NotARepository for a .git entry that leads to no valid Git directory, a .git file whose path ends in whitespace, or a .git file that names no folder.
  • GitReadError::Shallow, GitReadError::Reftable, GitReadError::Bare, GitReadError::ForeignWorktree or GitReadError::UnsupportedExtension.
  • GitReadError::TooLarge for a HEAD, a .git file or commondir over small_file_bytes, for a configuration file over config_bytes, or for an alternates file over alternates_bytes.
  • GitReadError::NotAFile for one of those entries that is a FIFO, a device, a socket, a dangling or refused symbolic link, or a folder other than .git.
  • GitReadError::Ref for a HEAD that cannot be parsed.
  • GitReadError::NotARepository also for a HEAD that names a ref outside refs/, or a commondir that is empty after its line ends.
  • GitReadError::Alternate for alternates over the count or the depth, an alternate that is not a folder, a quoted path, a relative path in a nested alternates file, or a folder that appears twice.
  • GitReadError::Config for a configuration that cannot be parsed.
  • An error for an unsupported format or version, or for a read error.
Examples
use gossil::git_reader::{GitReadError, GitRepository, Head, Limits};
use std::path::Path;

/// Return the parents of the commit at `HEAD`, or `None` for an unborn branch.
fn head_parents(worktree: &Path) -> Result<Option<Vec<String>>, GitReadError> {
    let repo = GitRepository::open(worktree, Limits::STANDARD)?;
    let tip = match repo.head()? {
        Head::Branch { tip, .. } => tip,
        Head::Detached(id) => Some(id),
    };
    let Some(tip) = tip else { return Ok(None) };
    let commit = repo.read_commit(&tip)?;
    Ok(Some(commit.parents().iter().map(|id| id.to_hex()).collect()))
}

// A folder without a `.git` entry is not a worktree. The open searches no parent folder.
let folder = tempfile::tempdir().unwrap();
let error = head_parents(folder.path()).unwrap_err();
assert!(matches!(error, GitReadError::NotAWorktree { .. }));
Parameter Type Description
worktree &Path Top folder of a main or linked worktree.
limits Limits Bounds of this call and of every later call.
returns Result<Self, GitReadError> The opened repository.
